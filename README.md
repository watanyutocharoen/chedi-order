# ระบบสั่งของงานเจดีย์ปากน้ำ 2569

เว็บแอปให้ทุกคนสั่งของจากร้านในงานร่วมกัน (ภาษาไทย) ข้อมูลเก็บใน Google Sheet ผ่าน Google Apps Script ไม่ต้องล็อกอินผู้ใช้

- `Code.gs` ฝั่งเซิร์ฟเวอร์ (Apps Script) เก็บข้อมูลลงชีต 4 แท็บ: people, shops, items, orders
- `Index.html` หน้าแอปทั้งหมด (ไฟล์เดียว) มีข้อมูลตั้งต้นฝังไว้ จะถูกใส่ลงชีตอัตโนมัติครั้งแรกที่เปิด

## ติดตั้ง
1. สร้าง Google Sheet ใหม่ → ส่วนขยาย → Apps Script
2. วาง `Code.gs` และเพิ่มไฟล์ HTML ชื่อ `Index` แล้ววางเนื้อหา `Index.html`
3. ทำให้ใช้งานได้ → เว็บแอป → เรียกใช้ในฐานะ "ฉัน" / ผู้มีสิทธิ์เข้าถึง "ทุกคน"
4. ส่งลิงก์เว็บแอปให้ทุกคน

หมายเหตุ: `Index.html` มีรายชื่อผู้สั่ง จึงควรเก็บ repo นี้เป็นส่วนตัว
